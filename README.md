# サンプル株式会社 ホームページ

会社・店舗紹介用の静的サイト（HTML / CSS）です。

## ファイル構成

| ファイル | 役割 |
|----------|------|
| `index.html` | ページの中身（文章・構成） |
| `style.css`  | 見た目（色・レイアウト） |

## 編集のしかた

- 文章を変える → `index.html` の `<!-- コメント -->` を目印に書き換え
- 色を変える → `style.css` 冒頭の `:root { --color-main: ... }` を変更

## ローカルで確認する

`index.html` をブラウザにドラッグ&ドロップするだけで表示できます。

## 公開する

GitHub にプッシュ後、Vercel か GitHub Pages で公開できます（手順は別途）。
