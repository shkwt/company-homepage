# プロジェクトマネジメント支援 コーポレートサイト

プロジェクトマネジメント支援事業の認知拡大と問い合わせ獲得を目的とした
コーポレートサイト（営業ツール）です。要件定義書をもとに制作しています。

## ファイル構成

| ファイル | 役割 |
|----------|------|
| `index.html` | TOP（1ページ完結のLP。全セクション） |
| `thanks.html` | お問い合わせ完了ページ |
| `style.css`  | 見た目（色・レイアウト・アニメーション） |
| `script.js`  | スクロールアニメーション |

## 掲載セクション（TOP）

Hero → 課題提起 → サービス → 強み → 支援実績 → プロジェクトの流れ →
プロフィール → FAQ → 大きなCTA → お問い合わせ → フッター

## 編集のしかた

- 文章 → `index.html` の該当箇所を書き換え（`<!-- コメント -->` が目印）
- 色 → `style.css` 冒頭の `:root { --navy / --blue / ... }` を変更
- 顔写真 → `profile.jpg` をこのフォルダに置き、`index.html` のプロフィール欄を画像に差し替え

## まだ「仮」になっている箇所

- プロフィールの氏名・経歴・保有資格
- お問い合わせフォームの送信先（メール連携は後日 Formspree 等で対応予定）
- 支援実績（現在は要件定義書の例のまま）

## デザイン方針（要件定義書より）

- カラー：ネイビー / ホワイト / ブルー / ライトグレー
- フォント：Noto Sans JP
- 余白を広く、カードUI、スクロールアニメーション、レスポンシブ対応

## 技術メモ（将来）

要件定義書では Next.js / TypeScript / Tailwind CSS / shadcn/ui、
ホスティング Vercel、DNS Cloudflare が指定されています。
現状は素早く公開できる静的サイト（HTML/CSS/JS）で実装。
将来ブログ等を追加する段階で Vercel + Next.js へ移行予定。
